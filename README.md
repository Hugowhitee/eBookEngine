# eBookEngine

A standalone, local-first Windows app for inspecting, cleaning, repairing, OCR-processing, editing and exporting EPUB and PDF documents.

The intended workflow is **Open → Preview → Improve → Review/edit → Save**. Ordinary repairs work without AI. Complex PDF reconstruction, document OCR and optional on-device AI are integrated capabilities, with in-app setup and visible progress. All generated changes must remain inspectable and reversible before saving.

**Current status:** Project foundations are defined; there is **no working application or Windows release yet**. A passing document or prototype is not proof of completed functionality.

See [PRODUCT.md](PRODUCT.md) for behavior and acceptance cases, [ARCHITECTURE.md](ARCHITECTURE.md) for technical contracts, [MILESTONES.md](MILESTONES.md) for implementation gates and [AGENTS.md](AGENTS.md) for contributor/Codex orientation.

No accounts, automatic cloud upload or bundled personal content are required.
